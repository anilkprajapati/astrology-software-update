# Astro Rishi for Android and iOS (OWNER NOTES)

An installable app (Capacitor) that opens the hosted site `https://app.astro-rishi.in` full screen, with the app icon, splash
screen and a "no internet" page. Logins, plans, permissions and payments are the hosted site's own — nothing is stored in the
app, and a site update shows up in the app at once. Android and iOS come from this one project; the native projects are
generated by the build, so only a few files live here (`capacitor.config.json`, `www/`, `assets/`).

## Build (GitHub does it, no phone SDKs needed on your PC)
Release repository on GitHub -> **Actions**:
- **Build Android app** -> Run workflow -> download `AstroRishi-Android-debug` (an `app-debug.apk`). Copy it to a phone, allow
  "install unknown apps", open it.
- **Build iOS app** -> Run workflow -> download `AstroRishi-iOS-simulator`. Unzip it on your Mac and drag `App.app` onto the iOS
  Simulator (Xcode -> Open Developer Tool -> Simulator). A real iPhone needs the Apple account below.

## To put the apps in the stores (accounts you do not have yet)
- **Google Play:** developer account, one-time US$25 (play.google.com/console). Then a signed release (`.aab`) is built with a
  keystore -- tell me when the account exists and I will add the signing step.
- **Apple App Store:** Apple Developer Program, US$99 per year (developer.apple.com). Needed for TestFlight, a real iPhone and the
  store. Tell me when it exists and I will add signing + upload.

## Things to know before the stores
- **Apple is strict about "just a website in an app"** (App Review guideline 4.2). Real native touches help: the offline page, splash
  screen, and later push notifications / share / saved-chart export to the phone's files. Expect possible review questions.
- **Payments:** if the site sells digital content or subscriptions inside the iOS app, Apple normally requires its own in-app
  purchase instead of Razorpay. Selling consultations / services is treated differently. Decide this before submitting.
- **Android** is far more relaxed; a debug APK works for private testing today.
- The site must have a **privacy policy** page and an account-deletion option (both stores require them; the site already has delete-account).
